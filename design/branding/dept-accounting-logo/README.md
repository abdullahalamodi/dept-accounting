# دبت للحسابات

A folded ledger inspired by the supplied Depty reference, with an upright document silhouette, ledger entries, and an addition symbol.

- Primary: #17654D (existing app primary token)
- Ivory: #F8E9DD
- logo.svg / logo.png: horizontal Arabic name lockup, PNG width 1600 px.
- logo-icon.svg / logo-icon.png: square symbol, PNG 1024 × 1024 px.

Both PNGs have transparent backgrounds. SVGs are self-contained, scalable, and editable. Arabic lettering uses the app’s IBM Plex Sans Arabic font and is converted to vector outlines for consistent rendering without installed fonts. No application code or installed app icons were changed.
