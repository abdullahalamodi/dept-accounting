# دبت للحسابات

تطبيق Flutter عربي لإدارة محل واحد دون إنترنت. هذه نسخة تطوير محلية، وليست إصدارًا معتمدًا للاستخدام التجاري.

يشمل الإعداد والمستخدمين المحليين، المنتجات والخدمات والوحدات، المخزون والافتتاح والجرد، العملاء والموردين، البيع والشراء والمسودات والمرتجعات، الاستلام السريع وتسوية التكلفة، الدفعات وتخصيص الأرصدة، المصروفات والتحويلات والمطابقة، المحاسبة التلقائية والتقارير والتصدير والنسخ المشفرة.

## التشغيل

Flutter 3.47.7 / Dart 3.13.5 استُخدما محليًا.

```bash
flutter pub get
dart run build_runner build
flutter run -d macos
```

على Windows استخدم `flutter run -d windows`. لبناء حزمة Windows نفّذ `./tool/build_windows.ps1` في PowerShell؛ أضف `-Installer` إذا كان Inno Setup 6 مثبتًا و`ISCC.exe` في PATH.

إجراء GitHub باسم **Build Windows** يعمل عند push وpull request، ويمكن تشغيله يدويًا عبر **Run workflow**. يستخدم إصدار Flutter المثبت في `.fvmrc`، ويتحقق من التبعيات المقفلة ويولّد النماذج ويشغّل التحليل والاختبارات قبل بناء Windows x64 بوضع release، ثم يجمع التطبيق وملفات DLL ومجلد `data` داخل مثبت EXE واحد باستخدام Inno Setup. لتنزيل المثبت افتح **Actions → Build Windows → التشغيل الناجح → Artifacts** واختر `دبت للحسابات-<version>-windows-setup.exe`؛ يُحفظ لمدة 14 يومًا ويُرفع مباشرة دون تغليفه داخل ZIP باستخدام `archive: false`. شغّل الملف على Windows لتثبيت التطبيق. المثبت يستخرج الملفات المطلوبة تلقائيًا وينشئ اختصارًا في قائمة ابدأ، مع خيار إضافة اختصار لسطح المكتب. هذا مثبت تطوير غير موقع. لم يُشغّل بناء المثبت على GitHub أو Windows من هذه الجلسة.

يتضمن بناء Windows مكتبات Visual C++ القابلة لإعادة التوزيع بجانب ملف التطبيق باستخدام `InstallRequiredSystemLibraries` في CMake، بما فيها `msvcp140.dll` و`vcruntime140.dll` و`vcruntime140_1.dll` والمكتبات المصاحبة التي يكتشفها CMake. يرفض Inno Setup إنشاء المثبت إذا غابت أي من هذه المكتبات الثلاث؛ لا يلزم تثبيت Visual C++ منفصلًا عند استخدام الحزمة الجديدة. يجب إعادة البناء للحصول على هذا التصحيح؛ لم يُتحقق من تشغيل الحزمة المصححة على Windows بعد.

`./tool/build_macos.sh` يبني حزمة تطوير macOS. التوقيع والتوثيق والتوزيع التجاري خطوات مستقلة. Android ما زال يستخدم إعداد توقيع التطوير الافتراضي؛ لا توزّع حزمة release قبل تجهيز توقيع خاص.

## مرجع تصميم الجوال

نموذج HTML تفاعلي محفوظ في [`prototypes/mobile-sales/`](prototypes/mobile-sales/README.md) لمراجعة تصميم الجوال وتطويره. افتح [`index.html`](prototypes/mobile-sales/index.html) مباشرة في المتصفح، أو شغّل من جذر المشروع:

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototypes/mobile-sales
```

ثم افتح [المعاينة المحلية](http://127.0.0.1:8765/). تظهر معاينة جوال على سطح المكتب، وتملأ الواجهة الشاشة على الجوال. لا يحتاج النموذج إلى Flutter أو تثبيت تبعيات؛ بياناته توضيحية وتُعاد عند تحديث الصفحة، ولا يتصل بقاعدة بيانات التطبيق. أوقف الخادم بـ `Ctrl+C`.

## بنية المشروع

`lib/features/` يفصل الميزات إلى بيانات وعرض وViewModels. `lib/core/` يضم قاعدة البيانات والجلسة والحساب الدقيق ومكونات تركيب الصفحات. `lib/design_system/` مرجع الواجهات المشترك؛ يمكن فتح معرضه من الإعدادات. التنقل بـ go_router، والحالة بـ ChangeNotifier، والنماذج بـ dart_mappable. ملفات `*.mapper.dart` مولدة؛ عدّل المصدر ثم أعد التوليد.

الاعتماد معاملة SQLite واحدة تحفظ المستند وحركات المخزون والقيود والتخصيص وسجل العملية. تستخدم المبالغ أعدادًا صحيحة بمنزلتين، والكميات بثلاث منازل، وتكلفة الوحدة بست. تغيير بطاقة الصنف لا يعيد كتابة المستندات المعتمدة.

## هوية التطبيق

اسم حزمة Dart والملفات التنفيذية هو `dept_accounting`، ومعرّف Android هو `com.amdi.dept_accounting`، ومعرّف macOS هو `com.amdi.deptAccounting`. اسم العرض العربي هو «دبت للحسابات».

تستخدم النسخ الجديدة امتداد `.dept_accounting`، ويظل استيراد النسخ القديمة بامتداد `.dukan` مدعومًا. تُنسخ قاعدة بيانات سطح المكتب السابقة إلى الاسم الجديد عند العثور عليها، دون حذف الأصل أو استبدال قاعدة موجودة بالاسم الجديد. تغيير معرّف Android أو حاوية macOS المعزولة يجعل النظام يعامل التطبيق كتثبيت جديد؛ انقل البيانات بنسخة مشفرة ومفتاحها إذا لم تكن البيانات القديمة متاحة من التثبيت الجديد.

أسماء Dukan المتبقية في الشيفرة مخصصة لقراءة البيانات السابقة فقط. مسارات الصور في `design-qa.md` أدلة تاريخية محفوظة بأسمائها الأصلية. معرّف مثبت Windows الثابت محفوظ لاستمرار التحديث وإلغاء التثبيت.

لتغيير معرّف Android أُضيفت أداة `change_app_package_name` ضمن تبعيات التطوير وشُغّل الأمر `dart run change_app_package_name:main com.amdi.dept_accounting --android`. الأداة تدعم Android وiOS فقط؛ معرّف macOS مضبوط منفصلًا بصيغة صالحة دون شرطة سفلية.
