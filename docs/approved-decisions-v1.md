# سجل القرارات المعتمدة — الإصدار الأول

> تحديث التنفيذ: بدأ بناء التطبيق بتوجيه المستخدم اللاحق في 15 أكتوبر 2026. أي ذكر أدناه لمرحلة «الوثائق فقط» يصف الاعتماد السابق؛ حالة التنفيذ الحالية في [سجل التنفيذ](implementation-progress.md).

**تاريخ الاعتماد:** 15 أكتوبر 2026.

**الحالة:** اعتمد المستخدم التوصيات في جولات المراجعة، مع إضافة الخدمات إلى نطاق الإصدار الأول، ثم أكد الفهم النهائي. التوجيه الحالي هو تثبيت القرارات في الوثائق فقط.

**الوثائق المرتبطة:** [المتطلبات الوظيفية](functional-requirements-v1.md)، [خطة التطوير](development-plan-v1.md).

## القرارات الأساسية السابقة للمقابلة

- السوق الأول هو اليمن، والتقنية Flutter.
- Windows هو منصة التطوير والإطلاق الأولى، ثم macOS وAndroid بقبول مستقل لكل منصة.
- جهاز واحد لكل محل، يعمل دون إنترنت؛ المستخدمون المحليون يتناوبون على الجهاز نفسه.
- يختار المحل عملة أساسية واحدة: الريال اليمني (YER) أو الريال السعودي (SAR). تعدد العملات وفروقات الصرف مؤجلان.
- نقل العمل إلى جهاز بديل يكون بالنسخ والاستعادة مع إيقاف استخدام النسخة القديمة؛ المزامنة ودمج تعديلات جهازين خارج نطاق الإصدار الأول.

## قرارات الجولة الأولى

| المرجع | الموضوع | القرار المعتمد |
| --- | --- | --- |
| Q1 | أول نشاط تجريبي | البدء بمحل أدوات منزلية أو كهربائية يبيع بالقطعة والكرتون، ثم التوسع لبقية الأنشطة ضمن نطاق المنتج. |
| Q2 | الخدمات | الخدمات ضرورية ومشمولة في الإصدار الأول، إلى جانب المنتجات المخزنية. |
| Q3 | الطرف عميلًا وموردًا | سجل بيانات واحد للطرف، وحساب منفصل لمعاملاته كعميل وآخر لمعاملاته كمورد، دون مقاصة تلقائية. |
| Q4 | الدفعات المقدمة والزائدة | السماح بدفعات قبل الفواتير أو أعلى من المستحق، وإظهارها رصيدًا لصالح الطرف يمكن استخدامه لاحقًا أو رده بسند. ينطبق ذلك على العملاء والموردين. |
| Q5 | المستندات القديمة | أثر المستند على المخزون والتكلفة يكون وقت اعتماده الحالي، مع حفظ تاريخ الورقة للمرجع؛ لا يُدرج داخل التسلسل السابق لإعادة حساب تكاليف المبيعات المرحلة. |
| Q6 | الأدوار | مالك بجميع الصلاحيات؛ بائع للبيع والقبض ضمن صلاحياته دون الاطلاع على التكلفة والأرباح أو إلغاء المستندات المعتمدة؛ محاسب للمشتريات والمصروفات والتسويات والتقارير. |
| Q7 | وجهة النسخ | نسخ تلقائي إلى مجلد يختاره المستخدم، وإمكانية النسخ إلى USB، وتنبيه عند تأخر النسخة الخارجية، مع عرض آخر نسخة ناجحة. |
| Q8 | الترخيص والتفعيل | تأجيل بناء التفعيل إلى ما بعد أول دورة تشغيل. تُستخدم النسخة الأولى للتجربة المباشرة، ويُحسم نموذج البيع والتفعيل قبل التوزيع التجاري، مع استمرار العمل اليومي دون إنترنت. |
| Q9 | الموعد والمراجعة | تطوير على مراحل دون موعد إطلاق ملزم حاليًا، ومراجعة محاسب قبل التجربة ببيانات حقيقية. |

## قرارات الجولة الثانية

| المرجع | الموضوع | القرار المعتمد |
| --- | --- | --- |
| Q10 | نطاق الخدمات | الخدمة بند في الفاتورة بسعر وكمية ووصف؛ لا يشمل الإصدار الأول نظامًا لاستلام أجهزة الصيانة أو متابعة الفنيين أو المواعيد. |
| Q11 | الوحدات والكسور | دعم الحبة والكرتون والمتر والكيلوجرام وغيرها من قائمة وحدات مُدارة ومشتركة؛ لكل صنف وحدة أساسية واحدة ووحدة إضافية اختيارية واحدة، بمعامل تحويل خاص بالصنف وتحديد قبول الكسور؛ يمكن منع كسر الحبة. التصنيفات قائمة مُدارة مستقلة، والقائمتان ببيانات أولية قابلة للتعديل والإيقاف مع حفظ الارتباطات والتاريخ. |
| Q12 | الافتتاح التدريجي | بدء البيع بعد إدخال الصندوق والأصناف المطلوبة، واستكمال باقي الأصناف والأطراف تدريجيًا. افتتاح كل صنف قبل أول حركة عليه؛ الفروق اللاحقة تُعالج بتسوية موثقة بدل تعديل الافتتاح. |
| Q13 | الاستلام السريع | تكلفة تقديرية إلزامية عند الاستلام قبل الفاتورة، مع اقتراح آخر تكلفة معروفة وإتاحة تعديلها، ثم تسوية الفرق عند وصول فاتورة المورد. |
| Q14 | تقسيم الدفع | توزيع الدفع على أكثر من حساب نقدي أو بنكي بعملة المحل نفسها، مع إبقاء غير المسدد آجلًا عند وجوده؛ يشمل المبيعات والمشتريات والسندات. |
| Q15 | السعر والخصم | خصم البائع ضمن حد يحدده المالك؛ تجاوز الحد أو تغيير السعر يدويًا يحتاج صلاحية إضافية. تُسجل هوية المستخدم والخصم والسعر الفعلي، وتوحد القاعدة بين البيع وPOS. |
| Q16 | توقيت النسخ | نسخ تلقائي كل ساعة أثناء وجود تغييرات، ومحاولة النسخ عند بدء التطبيق إذا فات الموعد، وقبل التحديث والاستعادة. النسخ إلى USB عند توفره، مع إظهار وقت آخر نسخة خارجية. |

## قرارات الجولة الثالثة

| المرجع | الموضوع | القرار المعتمد |
| --- | --- | --- |

| Q18 | تكاليف الخدمات | تسجيل أجور الفنيين وتكاليف التنفيذ كمصروفات، مع تقارير إيرادات الخدمات ومصروفاتها؛ لا تتبع لتكلفة وربح كل مهمة منفردة في الإصدار الأول. |
| Q19 | رد قيمة الخدمات | رد كلي أو جزئي بمستند مرتبط بالفاتورة وسبب، بصلاحية المالك أو المحاسب، دون حركة مخزون ودون تجاوز المبلغ المتبقي القابل للرد. |
| Q20 | حالة المرتجع | الصالح للبيع يعود للمخزون المتاح؛ التالف يُسجل استلامه وإتلافه بأثر موثق دون إتاحته للبيع، مع أثر مالي واضح للمرتجع. |
| Q21 | مصاريف الشراء | إضافة الشحن والنقل إلى تكلفة المنتجات اختياريًا، وتوزيعهما افتراضيًا حسب قيمة المنتجات، وفصلهما عن المصروفات التشغيلية. |
| Q22 | الدقة | منزلتان للمبالغ، وثلاث للكميات الكسرية، وست للحساب الداخلي لتكلفة الوحدة، مع تقريب موحد وتسوية آلية لفروقه. تُختبر حدود الدقة مع التحويل والمتوسط قبل تثبيت التنفيذ. |
| Q23 | العميل في البيع | فاتورة نقدية دون اشتراط العميل، واختياره اختياري لحفظ سجل مشترياته. اختيار العميل إلزامي إذا بقي مبلغ آجل. |
| Q24 | تثبيت العملة | يمكن تصحيح اختيار العملة أثناء الإعداد وقبل أول عملية مالية؛ يُمنع تغييره بعد أول عملية مالية. |

## حدود الاعتماد وما يُستكمل لاحقًا

- الخدمات البسيطة مشمولة؛ إدارة أوامر الصيانة والفنيين والمواعيد وتكلفة وربح كل مهمة والاستهلاك الآلي لموادها مؤجلة.
- اختيار المحل التجريبي الفعلي وطرازات الأجهزة والطابعات، وتعيين المراجع المحاسبي، مهام تسبق التجربة الميدانية؛ اعتماد التوجه لا يعني توفرها أو اختبارها.
- نموذج البيع وطريقة التفعيل لم يُختارا بعد؛ المؤجل هو تنفيذهما إلى ما بعد أول دورة تشغيل، ويُحسمان قبل التوزيع التجاري.
- تفاصيل توزيع خصم الفاتورة، والمطابقة المحاسبية للحركات المتداخلة وتسويات التكلفة، ومصفوفة الصلاحيات التفصيلية، وسياسة الاحتفاظ بالنسخ تُوثق وتُختبر عند تنفيذ الجزء المعني ضمن القرارات أعلاه.
- تقديرات المدة ليست موعد تسليم ملزمًا. أي تغيير في قرار معتمد يُحدّث في هذا السجل والمتطلبات والخطة معًا.
- هذا السجل يوثق النطاق والسلوك المطلوب؛ لا يُعد دليلًا على تنفيذ الميزات أو اختبارها أو جاهزيتها للعملاء.
