# ملاحظات التنفيذ وحدود القبول

هذه نسخة تطوير محلية مبنية على قرارات Q1–Q31. لا تحتوي تفعيلًا تجاريًا أو مزامنة أو فروعًا أو ضرائب أو أوامر صيانة، وفق النطاق المؤجل.

## القرارات التنفيذية

- SQLite مباشرة خلف مستودعات الميزات، دون مولّد استعلامات أو خادم. النماذج مولدة بواسطة dart_mappable. ViewModels من ChangeNotifier، والتنقل go_router، والتصميم من المكتبة الموجودة.
- مخطط إصدار 1، مع رفض قواعد أحدث من التطبيق. ملفات المحل في مجلد دعم التطبيق، منفصلة عن ملفات التثبيت. WAL ومعاملات IMMEDIATE وترقيم منفصل لكل نوع مستند.
- المبالغ بوحدات صحيحة ذات منزلتين، الكمية بثلاث، وتكلفة الوحدة بست؛ الضرب الوسيط بـBigInt. آخر إخراج كامل للصنف يستهلك كامل قيمته المتبقية لتصفير فروق التقريب.
- خصم الفاتورة والشحن يوزعان على البنود بحسب القيمة مع توزيع الباقي بالتتابع لضمان تطابق المجموع. شحن الشراء يدخل تكلفة المنتجات.
- التصحيح والإلغاء مستندات جديدة. إلغاء فاتورة ذات حركة مخزون لاحقة يُرفض؛ المرتجع يعالج الحالة دون إعادة كتابة تكلفة الماضي. فاتورة تسوية الاستلام لا تُلغى مباشرة؛ تستخدم مرتجعًا مرتبطًا.
- فروق تكلفة الاستلام تتتبع الكمية من نقطة الاستلام عبر الحركات التالية، وتُرحّل تسوية حالية للمخزون وتكلفة المباع أو التالف وفروق المرتجع. تكلفة البيع الأصلية تبقى كما اعتمدت؛ المرتجع اللاحق يأخذ أثر تسويات تكلفته. تحتاج الحالات المتداخلة مراجعة المحاسب قبل التشغيل الحقيقي.
- عجز وزيادة الجرد والمطابقة في حساب فروق المخزون/النقدية. تسوية أرصدة ما قبل البرنامج تقابل حساب الافتتاح قبل إقفاله، ثم رأس المال بعده، مع سبب وسجل.
- التخصيص منفصل عن القيد المالي. رد الرصيد يستهلك مصدره لمنع تخصيصه ثانية. إلغاء تخصيص الفواتير يسجل تفاصيل الربط السابق في سجل العملية.
- كلمات المرور ورمز استرداد المالك مشتقان بـPBKDF2-HMAC-SHA256 مع ملح عشوائي. النسخ بـAES-256-GCM ومفتاح عشوائي مستقل. قاعدة الجهاز نفسها تعتمد حماية حساب نظام التشغيل؛ لم تُضف مصادقة سحابية.
- النسخ يستخدم SQLite Backup API ثم تحقق فك التشفير وسلامة SQLite. يُنشأ ملف مؤقت ويُنقل إلى الاسم النهائي بعد الكتابة. نسخة محلية قبل الاستعادة، ونسخة مشفرة عند تغير إصدار التطبيق قبل ترقية المخطط. مجلدات macOS تحفظ bookmarks ضمن sandbox.
- التصدير يستخدم الخط العربي المحلي دون تنزيل خطوط أثناء العمل. Excel يحفظ القيم الظاهرة كنصوص دقيقة، ولا يحتوي صيغًا محاسبية. طباعة 80 مم تستخدم صفحات بطول 297 مم؛ القص والطابعة الفعليان يحتاجان تجربة مستقلة.
- الطباعة عبر خدمة النظام. لا تدعي هذه النسخة دعم جميع طابعات USB/Bluetooth أو أوامر ESC/POS الخام.

## حدود التحقق والتوزيع

اختبارات محلية مختصرة تغطي دورة التشغيل المعتمدة والترحيل الذري والمرتجعات وتسوية الاستلام والعربون والاستعادة والتصدير والتنقل. نجح بناء macOS للتطوير. لا يثبت ذلك قبول Windows أو Android أو الطابعات أو الأجهزة الفعلية.

أضيفت وصفة بناء Windows وحزمة Inno Setup وإجراء GitHub يدوي؛ لم يُنفذ Windows على هذه البيئة. التوزيع الحالي تطويري ومعرّفات الحزم ما زالت افتراضية. يلزم تثبيت هوية المنتج والتوقيع والتوثيق وقناة الدعم ونموذج التفعيل قبل التوزيع التجاري.

لا تُعدّل ملفات النسخ أو قاعدة SQLite يدويًا. عند فشل ترقية إصدار احتفظ بملفات المحل والنسخة السابقة؛ لا تفترض أن إصدارًا أقدم يقرأ مخططًا أحدث. الاستعادة على جهاز بديل وتجربة محل ومراجعة المحاسب والطابعات هي بوابات قبول منفصلة.
